# 芯片质检（焊点与飞线检查）· 飞线异常判定流水线

对芯片/电路板照片做自动质检：**逐产品给出"合格 / 不合格"结论**，并对飞线弯曲、飞线断联、焊盘裸露三类异常定位标注。

## 包含什么

- **完整推理流水线**：S1 候选点 → S2 焊点判定 → S3 飞线掩膜 → S4 掩膜分类 → S5 直度判定 → 逐产品报告
- **训练接口**（`train/`）：CNN 与 U-Net 的训练与数据准备脚本，供出现新缺陷形态时重训
- **做法与思路文档**（`docs/项目技术文档.md`）：环境要求、操作方法、每步算法原理、前处理 API 明细、重训指南
- 浏览器界面（`ui/app.py`，标准库 `http.server`，离线可用）与命令行入口（`run_pipeline.py`）
- `tools/make_release.py`：从交付目录导出本发布树（公开/不公开边界的书面依据）

## 不包含什么

| 不包含 | 原因 |
|---|---|
| 模型权重（`models/`） | 使用方的数据资产，不属于本程序源码；请自行训练（见 `train/README.md`）或使用自有权重 |
| 客户样品图与标注（`refs/` 等） | 客户数据，无授权不得公开 |
| `outputs/`、`backups/` | 运行产物与内部备份 |

因此**克隆后直接运行会因缺权重与参考数据而失败，这是预期行为**。

## 快速开始

```bash
pip install -r requirements.txt
cp 本地配置.env.example 本地配置.env      # 填本机路径与解释器（也可直接用环境变量）
python run_pipeline.py --input <图片目录> --out outputs
bash 启动_linux.sh                        # Windows: 双击 启动_windows.bat
```

## 环境变量

`CHIP_ROOT`（软件根）、`CHIP_DATA`（训练数据根）、`CHIP_PY`（解释器）、`CHIP_SRC`（只读源图）、`CHIP_PROJ`（工程数据）、`CHIP_LAB`、`CHIP_ANN`。代码中不含任何机器绝对路径。

## 验收基准

用 10 张样品跑全流程应得：**线段读数 117 ｜ 弯曲不合格 4 ｜ 断联 7 ｜ 裸焊盘 5**。数字不一致说明权重或参数与基准版本不同；严格复现需客户数据。


## 参考数据 `refs/` 怎么来（必须自备）

S4/S5 需要 `refs/`（`annot/` 归档掩膜 + `solder_table.json` 焊点表）。公开仓库不含它，用你**自己的图**两次操作生成：

```bash
# 第 1 步：先跑一次流水线，产出 masks/solder_table.json（真实焊点表）
python run_pipeline.py --input <图片目录> --out outputs

# 第 2 步：用这次运行生成 refs/（掩膜取自软件自身的板面分割，焊点表取自第 1 步）
python tools/make_placeholder_refs.py --src <图片目录> --out refs --from-run <第 1 步的运行目录>
```

实测：10 张样图 + 这一步产出的 `refs/` ⇒ 全链计数与基准一致（**读数 117 ｜ 弯曲 4 ｜ 断联 7 ｜ 裸焊盘 5**）。
只跑第 2 步不给 `--from-run` 会被拒绝（空焊点表会让整批被误判成"裸焊盘"）。
